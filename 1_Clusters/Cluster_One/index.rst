Cluster One
===========

Cluster One is the unified high-performance computing (HPC) system operated by ARCH at Johns Hopkins University. It combines the resources previously available on Rockfish, DSAI, and EDU clusters into a single platform. As of 2026, Cluster One consists of:

- CPU nodes with approximately 54,000+ cores across all partitions
- GPU nodes including NVIDIA A100 (40GB/80GB), H100 (80GB), H100-NVL (96GB), and L40S (48GB) accelerators
- Theoretical peak performance: approximately 4+ PFLOPs
- Multiple parallel file systems totaling ~13 PB of usable GPFS space plus 5 PB WEKA storage
- Network fabric: Mellanox HDR100 (1:1.5 topology)

These are "shared resources", therefore we expect all users to comply with policies on passwords, security guidelines, resource utilization and best practices, and privacy issues.

If users have any questions about these policies, please send an email to `help@arch.jhu.edu <mailto:help@arch.jhu.edu>`__
