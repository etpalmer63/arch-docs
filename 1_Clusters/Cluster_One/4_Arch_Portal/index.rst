Cluster One is accessible only to users and research groups with an approved allocation or user account.

Allocations and user accounts are managed through the `Arch Portal`_. All users -- whether internal or external -- must request access through this system.

.. note::
    All users should review the :doc:`Good Citizen guidelines <../../../4_Support/Citizen>` before requesting an allocation or account.
